Privacy Policy

Introduction

We respect your privacy and aim to protect information submitted while using My Store.

Information We Collect

This academic demonstration stores contact form submissions in a local JSON file and demo order details in another local JSON file when the Node.js server is running. The shopping cart is stored in your browser's local storage.

Use of Information

Submitted information is used to demonstrate contact forms, checkout, and order-management functionality for this project.

Cookies and Local Storage

The website uses browser local storage to remember the shopping cart. This demo does not need tracking cookies.

Third-Party Services

This project does not intentionally send form submissions to third-party services.

Data Security

This is an academic demo, not a production shopping platform. Do not enter sensitive personal information or real payment details.

Changes to This Policy

This privacy policy may be updated as the project develops.
