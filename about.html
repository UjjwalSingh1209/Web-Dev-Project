About Us

Welcome to My Store

My Store is a simple e-commerce platform designed to provide a clean and user-friendly online shopping experience.

This project is an Amazon-inspired e-commerce platform clone created as part of our Web Development subject. It focuses on designing the structure, layout, and styling of an online shopping website.

What We Offer

Our platform displays a variety of products including clothing, sports products, footwear, and home essentials.

Users can browse products, view product information, check their orders, and view items in their shopping cart.

Project Objective

The main objective of this project is to apply HTML, CSS, and JavaScript concepts to create a structured, responsive, and accessible e-commerce website with interactive features.

Technologies Used

  • HTML5
  • CSS3
  • JavaScript
  • Node.js built-in HTTP server
  • Local JSON file storage
  • Responsive Web Design and Accessibility Standards
